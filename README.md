# TPs
JavaScript Avancé – TP (Mini-Projet et Exercices)

Ce dépôt contient les exercices et un mini-projet pour un atelier avancé de JavaScript. Les principaux points abordés sont :

Syntaxe moderne ES6+ (let, const, fonctions fléchées, destructuring, spread/rest)

Manipulation d’objets, classes et méthodes sur les tableaux (map, reduce, filter, sort)

Programmation asynchrone avec Promises, async/await et l’API fetch

Un petit mini-projet interactif démontrant la manipulation du DOM et l’utilisation d’une API

Structure :

Partie 1 – Bases ES6 : Variables, fonctions, destructuring, spread operator

Partie 2 – Objets & Classes : Méthodes d’objets, classes ES6, opérations avancées sur les tableaux

Partie 3 – JavaScript Asynchrone : Promises, async/await, fetch API
