# TPs
TP3 – Travaux Pratiques TypeScript

Ce TP a pour objectif de pratiquer TypeScript et ses fonctionnalités avancées à travers une série d’exercices progressifs, allant des bases jusqu’à un projet concret de gestion de bibliothèque.

Contenu et objectifs :


Types de base et avancés : string, number, boolean, tableaux, tuples, enums, union, intersection, alias et assertions de type.

Objets et interfaces : création d’interfaces, héritage et propriétés optionnelles ou readonly.

Fonctions : fonctions avec paramètres optionnels, par défaut et surcharge.

Programmation orientée objet : classes, héritage, classes abstraites, interfaces, implémentation.

Génériques : fonctions et classes génériques pour un code réutilisable et typé.

Modules et organisation du code : import/export, ré-exportation, import type.

Outils et bonnes pratiques : strict mode, ESLint, Prettier pour un code propre et maintenable.

TP final – Projet réel :
Développement d’une application de gestion de bibliothèque avec :

Gestion des livres et utilisateurs

Emprunt et retour de livres

Classes abstraites, génériques et modules

Simulation d’un service API

Ce TP permet de maîtriser TypeScript et d’appliquer ses concepts dans un projet concret et bien structuré.
